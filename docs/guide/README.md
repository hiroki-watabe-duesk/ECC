# ハーネスエンジニアリング完全マスターガイド

このガイドは、ECC（Everything Claude Code）リポジトリの設計思想・仕組み・実践手法を体系的に解説します。単なる設定リファレンスではなく、「**ハーネスエンジニアリング**」という技芸を習得し、自分のプロジェクトへ応用できるエンジニアを育てることを目的としています。

**ハーネスエンジニアリング**とは、Claude Code・Codex・OpenCode・Cursor・Gemini・Zed などの複数の AI エージェントハーネス（実行面）を横断して一貫動作する、再利用可能・合成可能・永続的なエージェント型ワークフロー層を設計する技芸です。ECC はその参照実装であり、「ワークフローは一箇所に、ハーネスはアダプタで接続する」という中心命題を体現します。

## このガイドの使い方

**章間リンク**: 各章は他章の詳細説明には踏み込まず、相対リンクで参照します。同一トピックの重複説明はありません。

**ソース参照**: 記述はすべてリポジトリ内の実ファイルに基づいています。各章末の「参照ソース」節に該当ファイルのパスを示します。ソースを直接読むことで理解がさらに深まります。

**コードブロック**: パス・識別子・設定値はすべてリポジトリの実物に合わせています。コピーして使用できます。

**チェックリスト**: 実践的な章には作業チェックリストを含みます。自プロジェクトへの適用時にご活用ください。
